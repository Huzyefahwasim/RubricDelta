# Submission Checklist

## Qualification and integrity

- [ ] Individual submission
- [ ] Eligibility and registration information confirmed
- [ ] Original work and pre-existing components disclosed
- [ ] Dependency and asset licenses documented
- [ ] No secrets or private data
- [ ] Consequential changes require human approval
- [ ] Claims link to submitted evidence

## Deliverable 1: Code and engineering record

- [ ] Full source code
- [ ] Agent instructions
- [ ] README
- [ ] Tests
- [ ] Improvement Changelog
- [ ] Main failure mode
- [ ] Hot take supported by results

## Deliverable 2: Reproduction package

- [ ] Clean-environment setup
- [ ] Exact baseline command
- [ ] Exact advanced command
- [ ] Exact evaluation command
- [ ] Included benchmark data and expected outputs
- [ ] Model and dependency versions
- [ ] Runtime and cost

## Deliverable 3: Video

- [ ] Five minutes or less
- [ ] User problem
- [ ] Simple baseline
- [ ] Realistic end-to-end run
- [ ] Baseline versus final comparison
- [ ] Improvement changelog
- [ ] Largest contributor
- [ ] One removed experiment

## Deliverable 4: Trajectories

- [ ] Representative trajectory for each agent role
- [ ] Instructions and context
- [ ] Tool calls and results
- [ ] Feedback and retries
- [ ] Verification
- [ ] Human checkpoints
- [ ] Development-agent disclosure

## Scoring evidence

| Category | Points | Evidence |
|---|---:|---|
| Problem & User Value | 15 | README, user workflow, review-budget framing |
| Agent Solution & Engineering | 30 | architecture, role instructions, tools, retries, trajectories |
| End-to-End Quality | 20 | working interface, decisions, guarded export |
| Measured Improvement | 15 | fixed benchmark and paired evaluation report |
| Reproducibility | 15 | clean setup and exact commands |
| Hot Take / Insights | 5 | changelog, failure analysis, measured conclusion |
