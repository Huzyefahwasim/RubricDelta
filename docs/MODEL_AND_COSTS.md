## Replay disclosure

Replay mode uses a capture generated by the deterministic role implementations. The release contract contains 50 labeled offline calls:

- 10 direct-baseline calls, one per case;
- 40 advanced calls, covering rule compiler, change analyst, impact investigator, and independent verifier for each of 10 cases.

Replay records zero tokens, zero source latency, and zero cost because the captured source performs no remote model request. It must use the label `deterministic-role-capture`. Replay validates request order, prompt and source bindings, orchestration, and artifact generation. It provides no OpenAI performance evidence.

At the time this disclosure was drafted, Task 8 fixture generation and final validation were still in progress. The release owner must confirm that the committed fixture contains exactly 50 calls and passes the exact-replay validator before citing it as release evidence.

## Optional OpenAI path

The OpenAI path requires all of the following:

- an explicit `openai` provider flag;
- `OPENAI_API_KEY` on the server;
- an explicit pinned model ID.

An environment key alone cannot change the offline default. Provider errors fail the affected case and never substitute a deterministic ranking.

This repository has no verified live OpenAI evaluation result at the time of this disclosure. It therefore makes no live recall, token, latency, or dollar-cost claim. Estimated live cost remains `null` until a run records actual usage and a dated pricing source.

A future live report must include the exact model ID, repetition count, calls and attempts, input and output tokens, latency, price source and date, and failed or incomplete cases. The report must keep each repetition separate and show mean plus range.
